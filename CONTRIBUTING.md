# Panduan Berkontribusi

Terima kasih atas ketertarikan Anda untuk berkontribusi pada proyek Akun Google Switcher! Kami menyambut baik segala bentuk kontribusi, baik itu pelaporan kutu (bug), usulan fitur baru, perbaikan dokumentasi, maupun pengajuan kode (pull request).

## Cara Melaporkan Masalah (Bug)

Jika Anda menemukan celah atau kesalahan fungsi pada ekstensi ini, silakan buat laporan (issue) baru dengan menyertakan:
- Deskripsi singkat mengenai masalah yang terjadi.
- Langkah-langkah untuk mereproduksi masalah tersebut.
- Perilaku yang diharapkan versus perilaku yang terjadi.
- Versi Google Chrome yang Anda gunakan.

## Cara Mengusulkan Fitur

Kami sangat terbuka dengan ide-ide baru. Untuk mengusulkan fitur:
- Buat issue baru dan berikan label "enhancement".
- Jelaskan secara rinci fitur apa yang Anda inginkan dan bagaimana fitur tersebut dapat membantu pengguna lain.

## Aturan Pengajuan Kode (Pull Request)

1. Lakukan fork pada repositori ini ke akun GitHub Anda.
2. Buat cabang (branch) baru untuk fitur atau perbaikan Anda (contoh: `git checkout -b fitur-saya`).
3. Pastikan kode Anda mengikuti gaya penulisan yang sudah ada (struktur HTML, CSS, dan JavaScript murni).
4. Lakukan pengujian secara lokal dengan memuat ekstensi ini pada mode pengembang (Load unpacked) di Chrome Anda untuk memastikan semuanya berjalan lancar.
5. Lakukan komit perubahan Anda secara jelas dan ringkas (contoh: `git commit -m "Menambahkan fitur rotasi tema otomatis"`).
6. Dorong (push) cabang tersebut ke repositori fork Anda (`git push origin fitur-saya`).
7. Buat Pull Request dari cabang tersebut ke cabang utama (main) di repositori ini.

Kami akan meninjau kode Anda secepatnya. Terima kasih telah membantu membuat ekstensi ini menjadi lebih baik!
